# 账号等级和每日额度由人工开通

访客仍然每天 3 次，按 IP、按北京时间换日。登录后的排版次数改挂在账号上：没填每日额度就还是 3 次，填了就用那个数。计数按账号，不再跟这个人的 IP 绑在一起。邀请加成仍加在每天次数外面。`unlimitedUses` 为 true 时不扣次数，也不扣邀请加成。

后台在 `/admin`。能进去的人：不限次数的账号，或邮箱在 `ADMIN_EMAILS` 里。两种满足一种即可。等级分成 `free`、`member`、`admin`，只是标记。把等级改成 `admin` 不会自动获得后台，也不会自动不限次数。

不接支付。改等级和不限次数要再确认一次。每次写入记一条审计，优先放进 Blob `yooco-admin-audit`，存不上就打服务器日志。审计不写密码。
