## 参考组合

- 首页：Osmo 的产品与资源组织 + Made With GSAP 的可探索作品入口。
- 作品页：Obys 的精选目录思路 + 工具站清晰的筛选与卡片信息。
- 作品弹窗：Obys 的详情信息层次；建议新增从卡片展开到阅读预览的连续动画。这是 Yooco 提案，并非已确认的参考站动画。
- 工作台：借鉴 Osmo 的工具信息分层，动画集中在选中、展开和完成反馈；高频输入与调参立即响应。

## 当前功能边界

首页保留粘贴、上传、优化入口。作品页保留查看作品；弹窗保留做同款与配置下载。工作台保留预览、右侧参数、复制、优化、导入导出和恢复默认。

现有标题 SplitText、点阵和作品自动横滚均已存在。标题将增加更多设计版式并允许中英文变化，作品横滚按下方确认方案扩展。术语继续使用 CONTEXT.md 的气质方向、皮肤、造型等，不将网站视觉风格和文章排版参数混为一谈。

## 第一轮已确认

1. 网站第一眼：设计杂志气质为主，专业工具感为辅。
2. 改动幅度：展示页允许重新组织；工作台保留现有功能位置，允许通过视觉调整提升专业感。
3. 使用设备优先级：电脑优先。

## 第二轮已确认

1. 网站外壳：暖白、墨黑、少量绿色，作品预览保留各自配色；工作台用浅灰背景衬白色文章、统一控件与分隔线。
2. 首页标题：阿超要求增加更多设计感强的排版，可以包含中文和英文。六版构图与同义英文文案已确认。
3. 作品展示：首页保留慢速自动横滚，支持拖拽且悬停暂停；作品页用整齐网格与风格筛选。
4. 作品弹窗：接近全屏的阅读浮层，左侧文章、右侧固定说明与操作；卡片展开到预览，关闭回到原卡片位置。
5. 作品链接：本轮保持站内弹窗，不增加独立分享链接。

## 标题方案（已确认并实现）

- 六种构图：中文宋体居中、中文黑体左齐错层、中文大字配窄幅英文旁注、英文衬线居中、英文粗体左齐、中英文上下对照。
- 中文主句保持「把一篇好文章，排成读者愿意读完的样子」。英文推荐围绕同一含义，使用「Make a good article worth reading to the end.」，不新增宣传主张。
- 中文作为第一次访问时的首帧；即使标题使用英文，输入区用途提示仍保持中文。
- 每版在完整呈现后停留约五秒；采用逐行揭示、错层归位和字号层次变化。标题区高度稳定，输入框不随版式移动；输入时暂停轮播。
- 保留淡点阵。六版构图、英文文案与轮播细节均已获阿超认可。

未形成需要 ADR 的长期架构决策。参考站原始动画仍未完整核验；Yooco 自身实现已进行本地浏览器核验。

## 账号与订阅页补充（2026-09-23）

阿超新增登录、注册、订阅页设计。本轮重新核对了 [Osmo 登录](https://www.osmo.supply/login)、[Osmo 订阅](https://www.osmo.supply/plans)、[Obys 设计书库](https://library.obys.agency/)、[Made With GSAP](https://madewithgsap.com/get-started) 等公开页面。Osmo 已确认有独立登录入口、计费周期切换与会员方案；Obys 已确认使用书刊目录结构。以下是 Yooco 的设计推演，不是对参考站页面的复刻。

- 登录与注册：暖白外壳、浅绿杂志封面和清晰表单并置；用编号、英文微标题和中英文衬线标题建立书刊感。两个页面共用结构，通过不同主句区分状态。
- 订阅：借鉴 Osmo 的计费周期选择和方案对比，保留 Yooco 的免费试用、¥9.9/月、¥59.9/年。当前专业版权益未确定，页面明确标注预览、不可付款。
- 按钮：主操作使用现有浅绿渐变；免登录试用和其它次要入口使用高级灰。页面以静态排版为主，避免在账号输入期间播放强动效。
- 边界：当前没有账号和支付后端。账号页只展示可操作的本地流程预览，不发送或保存输入；订阅按钮禁用，工作台额度提示链接到方案说明。
## 本地实现与验证（2026-09-23）

- 首页：GSAP 六种中英文构图、约五秒停留、手动切换和暂停、输入聚焦时停留在可读状态；保留淡点阵与输入入口。
- 作品：首页自动横轨、鼠标拖拽防误触、暂停与前后浏览；作品页网格与风格筛选。
- 弹窗：近全屏双栏，手机改上下结构；展开/收回动效、Escape、焦点约束与返回、背景 inert 与滚动锁定。
- 工作台：仅精修外壳，保留位置和文章主题；修复做同款后正文加载但标题仍为默认文案的问题（renderBody 同步 model.title）。
- 浏览器：1440 桌面、375 与 320 窄屏检查；六种标题输入框坐标一致，无横向溢出。筛选 6→1→6、拖拽不误开、弹窗关闭回卡片、做同款标题/正文加载、暗色预览、复制成功提示均已观察。
- 构建：Next/EdgeOne 生产构建通过；变更 TS/TSX 文件定向 ESLint、TypeScript、public/app.js 语法检查通过。
- 下载：已点击配置下载，但浏览器自动化未返回 download 事件，文件落盘尚未确认；对象 URL 改为点击后一秒释放。
- 限制：未调用真实 AI 优化接口；未执行公网部署、Cloudflare 构建和公众号粘贴验收。减少动态偏好按代码检查，未切换系统设置实测。
- 本地预览采用 next start --port 5174。不要同时运行 vinext dev 与 next build：两者会写入不同的 .next/types/routes.d.ts，造成生成类型冲突；串行构建已通过。
