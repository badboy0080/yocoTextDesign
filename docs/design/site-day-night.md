# 首页和工作台的日夜皮肤

网站外壳改成暖米纸白天、暖黑夜间。文章主题和复制到公众号的 HTML 不跟着走。

## 颜色

白天：画布 `#F5EFE3`，纸面 `#FBF7EE`，字 `#211A12`，强调 `#A63A2B`。夜间：画布 `#0F0C0A`，卡片 `#1E1813`，字 `#F3ECDD`，强调字 `#CC6B57`。按钮填充仍用 `#A63A2B`，字 `#F3ECDD`，避免夜里浅砖红当按钮底看不清。小字白天 `#6E6353`，夜里 `#A89877`。

选择存在 `yooco-site-theme`。第一次没选过，跟系统。首页和工作台读同一份。脚本放在样式前面，避免先闪一下反色。

## 首页三拍

只用工作台示例《AI都会写文章了，公众号排版还得自己熬？》。顺序在 `lib/showcase-story.ts`：

1. 密排原稿，几乎没有标题层级。
2. 同一段文字展开成清氧绿成稿，标题、段距和重点句能读清。
3. 成稿只换皮肤，从清氧绿到深空青，字不动。

换样稿改 `public/samples/sample-try.js` 和 `SHOWCASE_INDEXES`。换顺序只改 `SHOWCASE_BEATS`。

桌面左栏的输入一直停在旁边。手机底部另有一条输入和试用，不锁滚动。减少动效时样稿静止、文字还在。脚本没跑起来时，成稿的备用稿仍在页面里。

## 工作台

桌面是四栏：现有导航、可折叠大纲、文章区、右侧设置（仍是 320px）。大纲可以搜标题，空搜索回到全部，点一条仍跳到对应段落。文章区的「手机预览」用微信手机框看排版，不换掉设置栏。预览纸色仍是当前文章主题。`public/site-chrome.css` 只画外壳，不写进复制稿。
