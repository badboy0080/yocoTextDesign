## 1. 背景与目标

### 产品定位

- 名称：**智能排版**
- 品牌句：Yooco · 好文章值得好排版
- 正式站：yoooco.com（三 o）
- **不是**公众号长文工作室里的「换一版」；是一套全新的**网格工作台**
- 挂入口：Yooco 左侧栏，「工作台」旁
- 独立页：`/layout.html`（类似现有 `/studio.html`）

### 目标（P0）

用户贴文案、可选上传多图，选一套模板骨架与画布比例，一点「生成排版」，得到可读的画布预览；生成后可在网格上拖动字块/图块微调；同模板可「换槽重排」再填一次。**本阶段只预览，不导出。**

## 3. 页面与信息架构

### 入口与路由

- 侧栏新增入口（「工作台」旁）→ `/layout.html`
- 不进入 `/studio.html` 的「换一版」流程

### 三区布局

| 区域 | 内容 |
| --- | --- |
| **左** | 贴文案（必填才能生成）；上传多图（可选） |
| **中** | 画布预览；**顶栏切比例**（3:4 / 1:1 / 16:9）；生成后可拖块；可视网格线（随格子数变化） |
| **右或底** | 选模板骨架（3 套）；「生成排版」；「换槽重排」；**格子数控件**（滑条或步进） |

### 页面流程

1. 用户贴文案（无文案则「生成排版」禁用）；可选上传图  
2. 选比例、选模板、调格子数（可保持默认）  
3. 点「生成排版」→ DeepSeek 只回槽填充 JSON → 前端按模板槽坐标渲染  
4. 用户可在画布上拖动字块/图块；拖动时吸附到网格线/交点  
5. 可选「换槽重排」：同模板再请求一次 AI 填槽（可带 seed）→ **直接覆盖**当前槽内容与位置（含用户拖过的位置），不弹确认  

### 格子数控件（P0 必有）

- 位置：预览区旁或右侧设置区  
- 形态：滑条或步进器二选一即可；展示当前「列数 N」  
- **默认 N = 12**  
- 可调范围：建议 6～24（步进 1）；超出范围钳制到边界  
- 调格子数时：网格线即时更新；已放置块在下一次拖动时按新网格吸附（不强制瞬间重吸附全部块，避免跳动）

## 4. 模板与槽模型

### 设计原则

- 层级分区（瑞士对齐 / banka 视频理论），**不是棋盘格填字**
- 每套骨架含：大标题区 + 副标/标签 + 正文块 + **1～3 个图槽**
- 三种比例各有一份槽坐标（**百分比**，随画布缩放）
- 槽类型仅四种：`H1` / `H2` / `body` / `image`

### 图与字边界

- 图不够 → 对应图槽**空着**（不报错）  
- 字太长 → 截/缩到槽内，预览提示「已截断」  
- 无图也可排（纯字）

### 模板清单（P0）

三套骨架，编号 `t1` / `t2` / `t3`。每套为三种比例各提供槽 id、类型、百分比框（`x/y/w/h`，相对画布 0～100）。具体坐标实现时按瑞士层级落位，本 spec 不锁死像素级数值，但要求：

- 同模板同比例下槽 id 稳定  
- 槽之间避免默认叠字  
- 图槽默认不压在正文可读区中心  

---

## 5. 画布拖动与网格吸附

### 含义澄清

- **初始位置**仍由「模板槽位 + AI 填槽」决定  
- **生成之后**，用户可拖动已渲染的 H1 / H2 / body / image 块，改位置（及合理范围内微调）  
- 这不是「用户自造模板」；模板骨架仍是 AI 起点与「换槽重排」的基准  
- **换槽重排直接覆盖**用户拖过的位置与填槽结果（选更简单路径，不二次确认）

### 网格定义（写死，无 TBD）

- 用户只调一个参数：**列数 N**（默认 **12**）  
- 画布按当前比例切成 **N 列**；**行数 M** 由比例推导，使单格接近正方形：  
  - 比例宽:高 = W:H 时，`M = round(N * H / W)`，且 `M >= 1`  
  - 例：N=12、3:4 → M = round(12×4/3) = 16；1:1 → M=12；16:9 → M = round(12×9/16) = 7  
- 格子线：垂直线在 `i/N`（i=0…N），水平线在 `j/M`（j=0…M），均以画布百分比计  

### 吸附规则

- 拖动时，块的**左上角**吸附到最近的格子**交点**（百分比坐标）  
- 吸附阈值：不超过半格（水平半格 = 50/N %，垂直半格 = 50/M %）  
- 块宽高在 P0 **不随拖动改变**（只改位置；改尺寸下期）  
- 拖出画布：钳制在画布内，使块仍至少保留可见的一角（实现可按块包围盒与画布求交）

### 不做（与拖动相关的边界）

- 不提供「保存为我的模板」  
- 不提供自由画新槽、删槽、改槽类型  
- 不提供双指缩放块、旋转

## 6. AI 填槽协议

### 请求（新提示词，不复用公众号 normalize/reroll）

请求携带：

- 原文全文  
- 图片张数（整数；无图为 0）  
- 当前比例：`"3:4"` | `"1:1"` | `"16:9"`  
- 选中模板 id（`t1`|`t2`|`t3`）及该模板在当前比例下的**槽清单**（id + type）  
- 可选 `seed`（换槽重排时传入，整数）

### 响应：模型只回 JSON

文本分段标 H1/H2/body 并映射到文字槽；图片用 `imageIndex`（从 0 起，对应用户上传顺序）映射到 image 槽。

示例形状：

```json
{
  "templateId": "t1",
  "ratio": "3:4",
  "seed": 42,
  "slots": [
    { "id": "h1", "type": "H1", "text": "标题原文摘句" },
    { "id": "h2", "type": "H2", "text": "副标或标签" },
    { "id": "body1", "type": "body", "text": "正文段落…" },
    { "id": "img1", "type": "image", "imageIndex": 0 },
    { "id": "img2", "type": "image", "imageIndex": 1 }
  ]
}
```

### 前端校验与回退

- 校验：每个 `slots[].id` 必须属于当前模板槽清单；`type` 与槽定义一致；`imageIndex` 为整数且 `0 <= index < 图片张数`（无图则不得出现有效 imageIndex）  
- 非法或缺槽 → **默认填法回退**（按槽顺序：首段进 H1、次段进 H2、其余进 body；图按上传顺序填满图槽，多出忽略，不足留空）  
- 超时或坏 JSON → 预览区展示「排版失败，再试一次」，**不扣次**

### 通道

走现有 DeepSeek 接口通道（环境变量与 EdgeOne 部署已有）。新路由或新 action 与 `/api/normalize` 分离，避免和公众号工作室耦合。

## 7. 边界与非目标

### 边界行为

| 情况 | 行为 |
| --- | --- |
| 无文案 | 「生成排版」禁用 |
| 无图 | 允许生成（纯字）；图槽空着 |
| 超时 / 坏 JSON | 「排版失败，再试一次」；不扣次 |
| 字溢出槽 | 截/缩；提示「已截断」 |
| 换槽重排 | 覆盖拖动结果；成功才扣次 |
| 试用额度 | 成功才扣；P0 暂跟工作台共用日额度，数字待定（下期） |

### 非目标（P0 明确不做）

- 导出图 / 导出 HTML（下期）  
- 用户自造模板、保存自定义骨架  
- 主题换肤（固定一套底色）  
- 第一期「换骨架」或一次出多套骨架候选  
- 纯坐标自由排（无模板）  
- 复用或修补 PR #70「换一版」进工作室主路径  

### 与 PR #70 的关系

PR #70「换一版」落在公众号工作室范围，**搁着不合**。智能排版另开 `/layout.html` 与独立填槽接口；不把 #70 当本功能基础合并。

## 8. 设计依据（落位规则摘要）

从 banka 小红书视频提炼，供实现对照：

- 层级：H1 / H2 / body / labels（本产品用 H1、H2、body；标签可落在 H2 槽）  
- 边线对齐；**层级优先于棋盘**  
- 图避免叠字；避免大留白乱绕排  
- 瑞士风格为默认气质  
- SEED 可重排（换槽重排带 seed，同骨架不同填法）  

网格是**微调与对齐工具**，不是把内容塞进棋盘格；初始构图仍靠模板层级分区。

---

## 9. 成功标准（P0）

1. 侧栏能进入 `/layout.html`  
2. 能选 **3 套模板 × 3 种比例** 并看到预览骨架/生成结果  
3. 贴文 + 可选图后，生成出**可读预览**  
4. 「换槽重排」能换填法、**不换骨架**；重排后覆盖此前拖动  
5. 生成后可拖动字块与图块；拖动时吸附到由列数 N 导出的网格交点  
6. 预览旁或设置内有**格子数控件**；默认 **N=12**；调节后网格线可见变化  
7. 无导出按钮，或导出灰掉并标注「下期」
