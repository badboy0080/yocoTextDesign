## 0. 理论底座（必写）

依据两份工作台备忘，下面是约束模板的话，不是书摘：

- `写给大家看的设计书-理论总结.md`（罗宾·威廉姆斯，CRAP）
- `平面设计中的网格系统-理论总结.md`（约瑟夫·缪勒-布罗克曼）

### CRAP 四条怎么管模板

四条一起用。少一条，版面会齐但平，或者醒目但乱。

- **亲密性**：同一件事的字靠在一起。组与组之间留出能看见的空行或空栏。日期和地点是一组，不要贴到大标题上。
- **对齐**：每个槽的边落在栏线或行线上。主对齐是左齐。信息多时不靠居中凑整齐。
- **重复**：五套共用三档字号（H1 / H2 / body）、同一左齐、同一种占位图。换模板要像一套海报。
- **对比**：标题和说明必须一眼能分开。只大一两号不算对比。图和字的面积也要分出主角，不要五五开。

用色跟对比、重复走：黑白或一个强调色就够。颜色不能成为把槽摆出格线的理由。

### 模块网格

网格是栏、行、模块搭成的骨架。模块是栏和行相交的那一格。

- 默认 **12 列**。12 能整分成 2、3、4、6，半版、三分、四分都是整数栏。列数滑条已有，本设计不改它。
- 行数沿用现有公式：`M = round(N × 高 / 宽)`，且至少 1 行。N=12 时：3:4 是 16 行，1:1 是 12 行，16:9 是 7 行。
- **空模块合法**。空是主动留的，不是没填满。每套至少留 1～2 个空模块，最好是一整行或一整栏。
- 字块和图块只占**整数格**。禁止半格悬空。
- **硬对齐**：边贴格线。差一像素的「差不多」不要。

页边距是字的安全边。图可以顶到画布边（出血）。字不要贴死四边。

### 换比例

换比例 = **同一套槽里的字和图** + **该比例自己的坐标**。

禁止把 3:4 的框整体拉成 1:1 或 16:9。那会把竖图拉扁，把标题拉变形。花瓣那组海报就是这条：内容同源，几何重摆。

槽 id 在三个比例里保持不变。填进去的字按 id 留着。变的只是占哪几栏、哪几行。

## 2. 画布规则（共用）

### 比例与坐标

- P0 沿用 **3:4 / 1:1 / 16:9**。每套模板为三个比例各写一套槽坐标。
- 栏、行从 1 起算，范围含两端。
- 下表按 N=12 和上面的行数写。实现换成百分比，边必须落在格线上：
  - `x = (左栏 − 1) / 12 × 100`
  - `w = 占栏数 / 12 × 100`
  - `y`、`h` 用同样算法，除以该比例的行数 M
- 不要抄现有 t1 那种 8%、6% 的框。那些数不在 12 栏线上。
- 用户改列数 N 时，只更新网格线。模板坐标仍按 12 列撰写。已有「下次拖动再吸附」的逻辑不动。

### 字

- 字号只三档：H1 标题、H2 副题、body 说明。不要再加第四档。
- 左齐为主。槽内已有的内边距负责字和格线之间的呼吸，不要再把字槽挪出半格。
- 标题可以折行。不要为了挤进一行，把标题缩到和正文差不多大。

### 空

- 每套至少留 1～2 个空模块。优先留一整行或一整栏，不要碎缝。

### 图槽

- 有图：`object-fit: cover`，裁在槽内，不破槽边。现有样式已是 cover，保持。
- 无图：图文模板显示对角 **X** 占位（槽内用样式画出，不引外链图片）。不隐藏图槽。
- 纯字模板没有图槽。
- 隐藏图槽还是画 X，本设计定为：**图文模板画 X**。和印象派参考图一致。

### 槽 id 与类型

角色写在 id 上。类型仍只用现有四种，填槽接口不用新类型。

| id | 类型 | 角色 |
| --- | --- | --- |
| title | H1 | 主标题 |
| subtitle | H2 | 副题 |
| date | body | 日期 |
| venue | body | 地点 |
| body | body | 说明 |
| credit | body | 署名 |
| image | image | 图。只有 C、D、E |

A、B 有前六个字槽，没有 image。C、D、E 七个都有。

## 5. UI

- 模板选择器显示 A–E。分成两组：**纯字**（A、B）、**图文**（C、D、E）。按钮上写简称，下面一行说明。
- 预置文案 3 个按钮：展览、自然、产品。
- 这三个按钮只填字槽。不请求 DeepSeek。不扣积分。不把文案写进左侧原文框。
- 用户已经上传的图保留。没有上传、且当前是图文模板时，图槽画 X。
- 默认：比例 3:4，模板 A，展览文案。打开页面就能看见字，不必先点生成。
- 切到 C、D、E：已填的字按 id 保留，并带上占位 X（已有上传图则用上传图）。
- 切回 A、B：字保留，不显示图槽。
- 换比例：套该模板该比例的坐标。已填的字和图保留。拖过的位置清掉，回到槽坐标。这和现在换比例会清掉拖拽偏移一致。
- 「生成排版」和「换槽重排」仍走原接口，成功才扣 1 积分，并覆盖预置字和拖拽位置。预置按钮不替代这两个按钮。

## 7. 验收

实现 PR 要有这些，本设计 PR 不截图。

- 纯字 A、B 各至少一张截图。
- 图文 C、D、E 各至少一张截图。图槽是 X 或一张上传图，cover 不破边。
- 同一条文案在 3:4、1:1、16:9 切换后：槽里的字不变，布局变。图没有被整张拉变形。
- 打开页面即是模板 A + 展览文案。点「自然」「产品」只换字，积分不变，不出现生成中的状态。
- 对照下面抽查，答得出「是」：

  1. 相关的字成组，组之间有空行或空栏。
  2. 槽边落在 12 栏和该比例的行线上。
  3. 五套都是左齐，字号只有三档。
  4. 标题和说明一眼能分出大小。
  5. 图占整数格，盖满槽内，不溢出。
  6. 每套能指出一块有意留白。
  7. 换比例是重摆坐标，不是整体拉伸。
