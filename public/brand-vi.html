02 / PRINCIPLES

先清楚，再好看。

Yooco 的视觉语言服务于写作和阅读。品牌标志保持轻快，内容排版保持清晰，装饰只在必要时帮助读者找到重点。以下原则用于指导新页面和新物料，属于本手册的应用建议。

01 / CLARITY

阅读优先

标题、导语、正文和辅助信息要有可识别的顺序，不用装饰代替内容层级。

02 / AIR

留白成节奏

用间距区分内容关系，让每个重点都有呼吸空间，而不是把每处都做成卡片。

03 / SPARK

轻快但克制

荧光绿只承担强调与识别。大面积正文仍由深墨与浅色底承载。

03 / MARK SYSTEM

一个表情，一眼认出。

主标志由气泡图形和专属矢量字标组成。气泡保留双眼与向右下方的软弧，不额外添加嘴巴或表情。正式使用请直接调用原始 SVG，不用字体重打字标。已有定稿

04 / COLOR

明亮一点，信息更清楚。

主绿负责识别和动作，深墨负责阅读，浅色底负责空间。以下前三色来自现有 Logo 交付规范；纯白为本册页面与应用示例的辅助色。

灵感绿文字 / 白底1.20:1对比不足，不用于小字
色值为屏幕 RGB / HEX。荧光绿的印刷还需要纸张、工艺、专色与实物打样；本册不把自动换算出的 CMYK 或 Pantone 当成最终标准。对比度按 WCAG 相对亮度公式计算，正文目标至少 4.5:1。

05 / TYPOGRAPHY

字体有分工，文章才有节奏。

Logo 字标是矢量图形，不由系统字体替代。界面和说明采用清楚的无衬线体；文章专题可在大标题使用宋体语感。以下字号为数字应用建议，具体页面可随内容调整。

界面与功能 / SANS

好内容，
读起来更好。

菜单、按钮、注释和操作说明以稳定、清晰为先。字体退化时保持系统可用，不依赖远程字体加载。

文章与专题 / EDITORIAL

把一篇好文章，
排成愿意读完的样子。

编辑感用在封面与标题，正文仍以舒适的字距、行距和栏宽支撑长时间阅读。

06 / LAYOUT

用栅格建立秩序。

版式要先照顾阅读顺序，再分配视觉重量。建议桌面采用 12 栏、手机采用 4 栏，间距按 8px 的倍数递进；这是为 Yooco 新物料制定的工作规范，不是 Logo 本身的几何数据。

标题先建立入口，
正文再给出答案。
图文不抢阅读顺序。相邻内容用共同边线或留白建立关系。

间距序列

8 / 16 / 24 / 32 / 48 / 64 px。相同层级重复相同距离，减少随意的微调。

长文栏宽

正文建议控制在 560–680px，手机两侧留足边距；避免一行过长或双列正文过窄。

07 / IMAGERY

图像补充内容，不替内容说话。

优先使用真实文章、真实人物与真实场景的图片。图像需要主体明确、留出标题空间，并保留来源和必要图注。本页图块只示意画面关系，不代表可直接使用的照片素材。

一个画面，
一个重点。
辅助细节
留作说明

图像选择规则

  • 只用获得使用权的真实图片；保留摄影或素材来源。
  • 同一篇文章中保持相近的明暗和裁切逻辑，不叠加荧光滤镜。
  • 标题压图前先检查对比；复杂图像可加纯色承托区。
  • 人物和重要物体不要被手机裁切吞掉。
  • 图像无法加载时，图注仍能说明内容。
图标延续气泡图形的圆润外轮廓与明确轮廓线，但不把两只眼睛复制成每个功能图标。功能图标首先要让用户看懂动作。

08 / VOICE

像编辑一样，把话说清楚。

品牌文案以内容和动作开头。说明用户现在能做什么、下一步会发生什么，避免夸张承诺。下列示例是本手册对已有工作台文案的延伸建议。

复制排版后，请检查图片与颜色。

避免 / NOISY

修饰多于信息。

11 / REFERENCE & GOVERNANCE

保持可查，也保持可更新。

本册把已交付的 Yooco Logo 规范与新拟定的应用规则放在一起。标志形状、色值、最小尺寸和留白来自现有资产说明；字体层级、栅格、图像与应用示例属于建议，正式印刷参数需打样确认。

使用优先级

先用本册提供的 SVG；已有品牌色与标志规则优先于应用示例。新场景先验证对比、可读性与授权。

版本维护

修改 Logo、主色或最小尺寸时同步更新源 SVG、网站和本册。新增模板应写明适用场景与不可用情况。

研究依据

  1. Atlassian: Brand guidelines template，品牌手册常见内容框架。
  2. IBM Design Language: Logo usage，标志留白、版本、背景和错误用法。
  3. IBM Design Language: 2x Grid，跨媒介栅格和间距系统。
  4. U.S. Web Design System: Theme color tokens，颜色按用途分配。
  5. W3C WAI: Contrast minimum，文字对比度检查。

资料用于确定 VI 手册的专业范围与可执行方式；页面中的 Yooco 规则是针对本品牌制定，不照搬参考品牌的标志、视觉元素或文案。
