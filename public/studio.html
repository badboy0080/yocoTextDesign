03网页风格
固定选择

先选一个视觉方向，左侧参数可继续微调。

识别逻辑
A
先把样式写回元素

项目先用 juice 把 class 和 style 规则内联，避免复制后样式丢失。

B
按文本长度加权统计

颜色、字号和行高出现得越多、承载文字越长，越可能成为主样式。

C
用结构判断组件

标题、引用、卡片、分隔线和图片按 DOM 规则计数，不靠单一颜色猜测。
